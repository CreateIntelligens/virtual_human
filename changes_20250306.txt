# 2025-03-06 系統改進記錄

## 1. 日誌系統改進
### 問題描述
- 日誌文件分散 (app.log 和 app_YYYYMMDD.log)
- 需要自動日誌輪換和清理機制
- 需要統一的日誌輸出方式

### 修改內容
1. 修改 logger.py：
   - 添加自動日誌輪換功能
   - 添加定時清理機制（保留7天）
   - 實現優雅的日誌處理

2. 實現功能：
   - 使用 app.log 作為當前日誌
   - 每天自動將前一天的日誌重命名為 app_YYYYMMDD.log
   - 自動刪除7天前的舊日誌
   - 每小時檢查一次是否需要輪換

## 2. 容器重啟機制優化
### 問題描述
- 容器停止後不能自動重啟
- 重啟策略配置衝突
- 需要改進服務依賴關係

### 修改內容
1. docker-compose.yaml 優化：
   - 移除複雜的 restart_policy 配置
   - 使用 restart: always 確保服務自動重啟
   - 改進服務依賴關係配置

2. 優化 app.py：
   - 添加信號處理（SIGTERM, SIGINT）
   - 實現優雅退出機制
   - 改進錯誤處理
   - 添加 SRS 服務可用性檢查

## 3. 實施步驟
1. 修改 logger.py：
```python
class CustomLogger:
    def __init__(self, name, log_dir='logs'):
        self.log_dir = log_dir
        self.current_log = 'app.log'
        self.retention_days = 7
        self.setup_logging()
        self.start_rotation_check()
```

2. 修改 docker-compose.yaml：
```yaml
services:
  srs:
    restart: always
  app:
    restart: always
    depends_on:
      srs:
        condition: service_started
```

3. 添加信號處理：

def handle_sigterm(signum, frame):
