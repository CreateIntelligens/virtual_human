# 實時字幕顯示功能實作說明

## 修改概述

為了實現當後端發送 `notify: {'status': 'start', 'text': '...'}` 事件時在前端顯示字幕的功能，我對以下檔案進行了修改：

## 1. 後端修改

### 1.1 修改 `basereal.py`

**新增功能：**
- 在 `BaseReal` 類別的 `__init__` 方法中添加事件存儲隊列：
  ```python
  self.notify_events = Queue(maxsize=100)  # 限制最多存儲 100 個事件
  ```

- 修改 `notify` 方法，除了原有的日誌輸出外，還將事件存儲到隊列中：
  ```python
  def notify(self,eventpoint):
      print(f'[{datetime.now()}] notify:',eventpoint)
      # 將事件存儲到隊列中
      try:
          if not self.notify_events.full():
              event_with_timestamp = {
                  'timestamp': datetime.now().isoformat(),
                  'event': eventpoint
              }
              self.notify_events.put(event_with_timestamp, block=False)
      except Exception as e:
          print(f'[{datetime.now()}] Error storing notify event: {e}')
  ```

- 新增 `get_notify_events` 方法來獲取所有待處理的事件：
  ```python
  def get_notify_events(self):
      """獲取所有待處理的 notify 事件"""
      events = []
      try:
          while not self.notify_events.empty():
              events.append(self.notify_events.get(block=False))
      except:
          pass
      return events
  ```

### 1.2 修改 `app.py`

**新增 API 端點：**
- 添加 `/get_notify_events` API 端點：
  ```python
  async def get_notify_events(request):
      """獲取 notify 事件"""
      params = await request.json()
      sessionid = params.get('sessionid', 0)
      
      # 等待 nerfreal 實例準備就緒
      if not await wait_nerfreal_ready(sessionid, timeout=5.0):
          # ... 錯誤處理
      
      try:
          events = nerfreals[sessionid].get_notify_events()
          return web.Response(
              content_type="application/json",
              text=json.dumps({
                  "code": 0,
                  "data": events
              }),
          )
      except Exception as e:
          # ... 錯誤處理
  ```

- 在路由配置中添加新端點：
  ```python
  appasync.router.add_post("/get_notify_events", get_notify_events)
  ```

## 2. 前端修改

### 2.1 修改 `rtcpushapi_google_split4.html`

**新增功能：**

1. **添加全域變數：**
   ```javascript
   let checkNotifyInterval;
   ```

2. **新增 notify 事件檢查函數：**
   ```javascript
   function startCheckingNotifyEvents() {
       checkNotifyInterval = setInterval(async () => {
           try {
               const response = await fetch('/get_notify_events', {
                   method: 'POST',
                   headers: {
                       'Content-Type': 'application/json'
                   },
                   body: JSON.stringify({
                       sessionid: parseInt(sessionId)
                   })
               });
               const result = await response.json();
               
               if (result.code === 0 && result.data && result.data.length > 0) {
                   result.data.forEach(eventData => {
                       const event = eventData.event;
                       console.log('Received notify event:', event);
                       
                       // 當收到 status: 'start' 時顯示字幕
                       if (event && event.status === 'start' && event.text) {
                           showSubtitle(event.text);
                       }
                   });
               }
           } catch (error) {
               console.error('Error checking notify events:', error);
           }
       }, 300); // 每 300ms 檢查一次
   }
   ```

3. **新增字幕顯示函數：**
   ```javascript
   function showSubtitle(text) {
       const aiResponseDisplay = document.getElementById('aiResponseDisplay');
       if (aiResponseDisplay) {
           // 清除可能存在的淡出定時器
           if (window.subtitleFadeTimer) {
               clearTimeout(window.subtitleFadeTimer);
           }
           
           // 顯示字幕
           aiResponseDisplay.textContent = text;
           aiResponseDisplay.style.opacity = '1';
           aiResponseDisplay.style.transition = 'opacity 0.3s ease-in-out';
           
           console.log('Showing subtitle:', text);
           
           // 設定字幕顯示時間（根據字數計算，最少 3 秒，最多 10 秒）
           const displayTime = Math.max(3000, Math.min(10000, text.length * 150));
           
           // 設定淡出效果
           window.subtitleFadeTimer = setTimeout(() => {
               aiResponseDisplay.style.opacity = '0.3';
               // 完全隱藏後恢復預設文字
               setTimeout(() => {
                   if (aiResponseDisplay.style.opacity === '0.3') {
                       aiResponseDisplay.textContent = '請開始對話...';
                       aiResponseDisplay.style.opacity = '1';
                   }
               }, 300);
           }, displayTime);
       }
   }
   ```

4. **修改初始化程式碼：**
   ```javascript
   $(document).ready(async function() {
       $('#rtc_media_player').prop('muted', true);
       startCheckingSpeakingStatus();
       startCheckingNotifyEvents(); // 啟動 notify 事件檢查
       await initializeUIWithConfig();
       startPlay();
   });
   ```

5. **添加清理程式碼：**
   ```javascript
   window.onbeforeunload = function() {
       // ... 其他清理程式碼
       if (checkNotifyInterval) {
           clearInterval(checkNotifyInterval);
       }
   };
   ```

## 3. 工作流程

1. **後端事件產生：** 當 TTS 開始說話時，`basereal.py` 中的 `notify` 方法會被調用，同時將事件存儲到隊列中
2. **前端輪詢：** 前端每 300ms 調用 `/get_notify_events` API 來檢查是否有新的 notify 事件
3. **事件處理：** 當收到 `status: 'start'` 的事件時，前端會調用 `showSubtitle` 函數
4. **字幕顯示：** 字幕會顯示在 `aiResponseDisplay` 元素中，根據文字長度自動計算顯示時間
5. **自動隱藏：** 字幕會在指定時間後自動淡出，並恢復原始提示文字

## 4. 特性

- **即時性：** 300ms 的輪詢間隔確保字幕能夠即時顯示
- **智能顯示時間：** 根據文字長度自動計算顯示時間（3-10 秒）
- **平滑動畫：** 使用 CSS transition 實現平滑的淡入淡出效果
- **資源管理：** 適當的定時器清理，避免記憶體洩漏
- **錯誤處理：** 包含完整的錯誤處理機制

## 5. 使用方式

系統啟動後，當虛擬人開始說話時（觸發 `notify: {'status': 'start', 'text': '...'}` 事件），對應的文字會自動在前端顯示為字幕，無需任何手動操作。
